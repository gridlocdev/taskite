# Workspaces (PRD §14)

Each slice leaves `just check` green and fits one session.

- [x] **1. Engine model.** `workspaces.json` in `packages/core`: the type, reading with `normalize` rules (missing file → `main` "Tasks", `main` put first, bad or repeated entries dropped, unknown fields kept), writing, `addWorkspace`, `renameWorkspace` (80 characters, unique ignoring case), `removeWorkspace` (never `main`), `isWorkspaceId`, and `workspaceDataPath(id)` (`tasks.json` or `workspaces/<id>/tasks.json`). Unit tests. Waits on nothing.
- [x] **2. Store per workspace.** A `WorkspaceStore` beside `TaskStore`: `loadList()`/`saveList(text, expected)` for `workspaces.json`, `open(id): TaskStore`, `deleteFolder(id)`/`restoreFolder(id)` (to and from `workspaces/.deleted/`). In every adapter: memory, browser (OPFS subfolders), native (bridge takes the id; main checks it before building a path; iOS bridge too), NAS (`/api/workspaces`, `?workspace=` on the existing routes, server tests for bad ids). The store contract test runs per workspace. `taskite.unsaved.<id>` with the old key read as `main`'s. Waits on 1.
- [ ] **3. Switching in the app.** The controller holds the workspace list and the open id (`taskite.workspace`), and switches: flush the pending save, stop on failure, load the other file, clear undo, open its `lastView`. Theme and every setting come from the open file. Re-read `workspaces.json` on focus; deleted-elsewhere fallback. Window title. Unit tests on the switch logic. Waits on 2.

Waits on 3.
- [ ] **5. CLI.** `--workspace` / `$TASKITE_WORKSPACE`, `taskite workspaces` (with `--json`), `path` per workspace, the CLI's skill doc. Tests. Waits on 2.
- [ ] **6. Docs and release notes.** `docs/features.md`, `docs/architecture.md`, `docs/getting-started.md` if it names the file, CHANGELOG under Unreleased. Waits on 4 and 5.
