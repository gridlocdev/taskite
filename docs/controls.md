# Controls

Every action is in the menu bar, in the **command menu** (**⌘K** on a Mac, **Ctrl+K** on Windows and Linux), and in the **Keyboard Shortcuts** window (**?** or **Help → Keyboard shortcuts**). That window is built from the same list as the menus, so it is always up to date.

Single-letter keys only work when you aren't typing in a box.

## Adding tasks

| Action | macOS | Windows / Linux |
|---|---|---|
| New task | **Q**, **N** or **⌘N** | **Q**, **N** or **Ctrl+N** |
| Save the task and start the next one | **↵** | **Enter** |
| Stop adding | **↵** on an empty row, or **Esc** | **Enter** on an empty row, or **Esc** |

## Choosing tasks

| Action | macOS | Windows / Linux |
|---|---|---|
| Next / previous task | **↓** / **↑** (or **J** / **K**) | **↓** / **↑** (or **J** / **K**) |
| Add the task below / above | **⇧↓** / **⇧↑** | **Shift+↓** / **Shift+↑** |
| Add or remove one task | **⌘-click** | **Ctrl-click** |
| Choose a range | **Shift-click** | **Shift-click** |
| Choose all tasks in the list | **⌘A** | **Ctrl+A** |
| Clear the choice | **Esc** | **Esc** |
| Menu of actions | Right-click a task | Right-click a task |

## Working on the chosen tasks

| Action | macOS | Windows / Linux |
|---|---|---|
| Complete, or reopen if already done | **Space** | **Space** |
| Edit (one task) | **↵** | **Enter** |
| Set due date | **D** | **D** |
| Priority 1 to 4 | **1**, **2**, **3**, **4** | **1**, **2**, **3**, **4** |
| Move to a project | **M** | **M** |
| Move to the Trash | **⌫** or **⌦** | **Backspace** or **Delete** |
| Restore (in the Trash) | **R** | **R** |
| Delete forever (in the Trash) | **⌫** or **⌦** | **Backspace** or **Delete** |
| Undo | **⌘Z** | **Ctrl+Z** |
| Redo | **⇧⌘Z** | **Ctrl+Shift+Z** or **Ctrl+Y** |

## Going places

| Action | macOS | Windows / Linux |
|---|---|---|
| Inbox | **G** then **I** | **G** then **I** |
| Today | **G** then **T** | **G** then **T** |
| Upcoming | **G** then **U** | **G** then **U** |
| Completed | **G** then **C** | **G** then **C** |
| Trash | **G** then **X** | **G** then **X** |
| Search | **/** or **⌘F** | **/** or **Ctrl+F** |
| A project or label | **⌘K**, then type its name | **Ctrl+K**, then type its name |

## Help

| Action | macOS | Windows / Linux |
|---|---|---|
| Command menu | **⌘K** or **⌘P** | **Ctrl+K** or **Ctrl+P** |
| Keyboard shortcuts | **?** or **⌘/** | **?** or **Ctrl+/** |
| Close a window or clear search | **Esc** | **Esc** |
