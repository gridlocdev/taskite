# Controls

Every action is in the menu bar, in the **command menu** (**⌘K** on a Mac, **Ctrl+K** on Windows and Linux), and in the **Keyboard Shortcuts** window (**?** or **Help → Keyboard shortcuts**). That window is built from the same list as the menus, so it is always up to date.

Single-letter keys only work when you aren't typing in a box.

In a browser tab, the browser keeps **⌘N** and **⇧⌘N** (**Ctrl+N** and **Ctrl+Shift+N**) for its own windows, so use **N** there, or **⌘K** and type "new project". The desktop app has both.

## Adding tasks

| Action | macOS | Windows / Linux |
| --- | --- | --- |
| New task | **⌘N** or **N** | **Ctrl+N** or **N** |
| New project | **⇧⌘N** | **Ctrl+Shift+N** |
| Save the task and start the next one | **↩** | **Enter** |
| Stop adding | **↩** on an empty row, or **⎋** | **Enter** on an empty row, or **Esc** |

## Choosing tasks

| Action | macOS | Windows / Linux |
| --- | --- | --- |
| Next / previous task | **↓** / **↑** (or **J** / **K**) | **Down** / **Up** (or **J** / **K**) |
| Add the task below / above | **⇧↓** / **⇧↑** (or **⇧J** / **⇧K**) | **Shift+Down** / **Shift+Up** (or **Shift+J** / **Shift+K**) |
| First task of the next / previous section (list) | **⌥⇧↓** / **⌥⇧↑** | **Alt+Shift+Down** / **Alt+Shift+Up** |
| Task level with this one in the next / previous column (board) | **→** / **←** | **Right** / **Left** |
| First task of the next / previous column (board) | **⌥⇧→** / **⌥⇧←** | **Alt+Shift+Right** / **Alt+Shift+Left** |
| Add or remove one task | **⌘-click** | **Ctrl-click** |
| Choose a range | **Shift-click** | **Shift-click** |
| Choose all tasks in the list | **⌘A** | **Ctrl+A** |
| Clear the choice | **⎋** | **Esc** |
| Menu of actions | Right-click a task (or **⇧F10**) | Right-click a task (or **Shift+F10**) |

## Working on the chosen tasks

| Action                              | macOS                      | Windows / Linux                |
| ----------------------------------- | -------------------------- | ------------------------------ |
| Complete, or reopen if already done | **␣**                      | **Space**                      |
| Edit (one task)                     | **↩**                      | **Enter**                      |
| Save and close the task editor      | **⌘↩**                     | **Ctrl+Enter**                 |
| Set due date                        | **D**                      | **D**                          |
| Priority 1 to 4                     | **1**, **2**, **3**, **4** | **1**, **2**, **3**, **4**     |
| Move to a project                   | **M**                      | **M**                          |
| Move up / down in the project       | **⌥↑** / **⌥↓**            | **Alt+Up** / **Alt+Down**      |
| Move to the previous / next section | **⌥←** / **⌥→**            | **Alt+Left** / **Alt+Right**   |
| Move to the Trash                   | **⌫** or **⌦**             | **Backspace** or **Delete**    |
| Restore (in the Trash)              | **R**                      | **R**                          |
| Delete forever (in the Trash)       | **⌫** or **⌦**             | **Backspace** or **Delete**    |
| Undo                                | **⌘Z**                     | **Ctrl+Z**                     |
| Redo                                | **⇧⌘Z** or **⌘Y**          | **Ctrl+Shift+Z** or **Ctrl+Y** |

| --- | --- | --- |
| Inbox | **G** then **I** | **G** then **I** |
| Today | **G** then **T** | **G** then **T** |
| Upcoming | **G** then **U** | **G** then **U** |

| --- | --- | --- |
